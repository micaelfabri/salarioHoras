# Calculadora Hora/Salário

Calculadora simples que retorna o valor da hora trabalhada de um funcionário, com base no salário mensal e no total de horas trabalhadas no mês.

![Tela da calculadora](assets/screenshot.png)

## Como usar

1. Abra o arquivo `index.html` no navegador (não precisa de servidor nem instalação).
2. Preencha nome, salário mensal e horas trabalhadas no mês.
3. Clique em **Calcular**.
4. O valor da hora aparece formatado em reais (ex: `R$ 18,75`) logo abaixo do botão.

Se as horas trabalhadas forem `0` ou algum campo estiver inválido, a calculadora mostra "Dados inválidos" em vez de travar ou calcular errado.

## Tecnologias

HTML, CSS e JavaScript puro — sem frameworks, sem build, sem dependências.
