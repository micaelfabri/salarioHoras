                   💵 Calculadora Hora/Salário 💵

💰 O programa vai retornar o valor hora do funcionário com base no seu salário mensal e nas suas horas trabalhadas naquele mês. 💰

💻 Passos:
    1- Fazer inputs para que seja cadastrado cada valor (salário mensal, horas trabalhadas) e cada dado do funcionário;
    2- Guardar todas essas informações;
    3- Calcular todos os valores e retornar para o usuário estes valores;
